## Study Pattern for Each Topic

1. Read the explanation.
2. Run the commented example.
3. Predict the output before executing it.
4. Complete three exercises.
5. Solve one LeetCode-style problem.
6. Solve one whiteboard-style question.
7. Complete the short quiz.
