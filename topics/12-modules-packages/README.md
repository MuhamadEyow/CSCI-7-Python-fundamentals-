# Modules and Packages

## Learning Objectives

- Import Python modules.
- Organize reusable code.
- Use virtual environments and dependencies.
- Create a simple package structure.

## Topic Files

Add or complete these files as you study:

- `notes.md` — Explanation in your own words
- `examples.py` — Commented examples
- `expected_output.txt` — Predicted program output
- `exercises.py` — Three practice problems
- `quiz.md` — Knowledge check
- `leetcode.py` — LeetCode-style problem
- `whiteboard.py` — Interview-style problem

## Completion Checklist

- [ ] I can explain the concept without reading my notes.
- [ ] I can write a basic example from memory.
- [ ] I completed three exercises.
- [ ] I passed the quiz.
- [ ] I solved one LeetCode-style problem.
- [ ] I explained one whiteboard solution aloud.
