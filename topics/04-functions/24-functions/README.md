# 24. Functions

## What It Is

Functions package reusable behavior into named units. They improve organization, reduce repetition, and make code easier to test.

## What to Complete

Use the [topic study template](../../../course-info/TOPIC_TEMPLATE.md) and add:

- `notes.md` — Your explanation in simple language
- `examples.py` — Commented code examples
- `expected_output.txt` — Output predicted before running the code
- `exercises.py` — Three problems: beginner, intermediate, and applied
- `quiz.md` — Concept, output-prediction, and debugging questions
- `leetcode.py` — One related LeetCode-style problem
- `whiteboard.py` — One interview-style question explained aloud

## Completion Checklist

- [ ] I can explain this concept without notes.
- [ ] I can write an example from memory.
- [ ] I completed three exercises.
- [ ] I passed the quiz.
- [ ] I solved the LeetCode-style problem.
- [ ] I explained the whiteboard solution aloud.
