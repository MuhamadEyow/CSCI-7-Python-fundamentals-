# CSCI E-7: Python Fundamentals

This repository organizes my Python course, learning topics, assignments, projects, and resources in one simple structure.

## Folder Structure



| Folder | What It Contains |
|---|---|
| [`course/`](course/) | Course overview, study plan, topic template, and progress tracker |
| [`topics/`](topics/) | The 50 Python fundamentals in learning order |
| [`assignments/`](assignments/) | Course assignments and submitted work |
| [`projects/`](projects/) | Small and large Python projects |
| [`resources/`](resources/) | Documentation, tutorials, and reference material |

## How I Use This Repository

1. Choose the next concept from the [topics folder](topics/).
2. Solve one LeetCode-style problem and one whiteboard-style problem.
3. Apply several concepts together in [projects](projects/).
4. Update the [progress tracker](course/PROGRESS_TRACKER.md).
