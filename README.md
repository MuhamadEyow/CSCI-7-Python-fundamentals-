# CSCI E-7: Python Fundamentals

A complete, structured roadmap for learning the **50 most important Python fundamentals** through explanations, commented code, expected output, exercises, quizzes, and interview practice.

## Learning System

Every fundamental follows the same process:

1. Understand what the concept is and why it matters.
2. Study commented Python examples.
3. Predict the output before running the code.
4. Complete three exercises: beginner, intermediate, and applied.
5. Take a short quiz.
6. Solve one LeetCode-style problem.
7. Explain and solve one whiteboard-style question.
8. Update the [progress tracker](course-info/PROGRESS_TRACKER.md).
