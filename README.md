# CSCI E-7: Python Fundamentals

A structured learning repository for building strong Python fundamentals through explanations, commented code, practice, quizzes, and interview-style problems.

## Learning Goal

For every topic, I will learn the concept, predict and run code, solve exercises, complete a quiz, and practice one LeetCode-style and one whiteboard-style problem.

## Repository Structure

| Folder | Purpose |
|---|---|
| `course-info/` | Course roadmap, progress tracker, and reusable study template |
| `topics/` | Python concepts arranged in recommended learning order |
| `assignments/` | Submitted coursework organized by assignment |
| `projects/` | Larger programs that combine several concepts |
| `resources/` | Official documentation and helpful references |

## Study Workflow

For each topic:

1. Read the explanation in `README.md` or `notes.md`.
2. Review and run `examples.py`.
3. Predict the result before checking `expected_output.txt`.
4. Complete at least three problems in `exercises.py`.
5. Take the quiz in `quiz.md`.
6. Solve the topic's LeetCode-style problem.
7. Explain and solve the whiteboard-style question aloud.
8. Mark the topic complete in the [progress tracker](course-info/PROGRESS_TRACKER.md).
