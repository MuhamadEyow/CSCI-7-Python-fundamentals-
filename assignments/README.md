# Assignments

This folder contains formal course assignments.

Use one numbered folder for each assignment:

```text
assignments/
├── 01-assignment-name/
│   ├── README.md
│   ├── solution.py
│   ├── expected_output.txt
│   └── tests/
└── 02-assignment-name/
```

Each assignment README should explain the objective, requirements, how to run the code, expected output, and lessons learned.

Do not publish private course material, credentials, or solutions when the course policy prohibits sharing them.
