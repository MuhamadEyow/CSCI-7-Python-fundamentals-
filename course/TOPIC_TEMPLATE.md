# Topic Template

Use this structure inside each topic folder:

```text
topic-name/
├── README.md
├── notes.md
├── examples.py
├── expected_output.txt
├── exercises.py
├── quiz.md
├── leetcode.py
└── whiteboard.py
```

- `README.md` — Topic purpose and checklist
- `notes.md` — Explanation in simple language
- `examples.py` — Commented examples
- `expected_output.txt` — Predicted and verified output
- `exercises.py` — Beginner, intermediate, and applied exercises
- `quiz.md` — Concept, output, and debugging questions
- `leetcode.py` — One LeetCode-style problem
- `whiteboard.py` — One interview-style problem
