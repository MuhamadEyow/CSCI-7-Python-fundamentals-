# Study Plan

Use this seven-step process for each Python topic:

1. Read the explanation and rewrite it in your own words.
2. Study the commented examples.
3. Predict the output before running the code.
4. Complete three exercises: beginner, intermediate, and applied.
5. Complete the quiz and correct every mistake.
6. Solve one LeetCode-style problem.
7. Explain and solve one whiteboard-style problem aloud.

After completing a topic, update the [progress tracker](PROGRESS_TRACKER.md).
